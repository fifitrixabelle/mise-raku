# mise-raku Implementation Plan

**Goal:** Install official Rakudo releases through a modern mise-only plugin.
**Architecture:** Three Lua hooks share release-index and checksum handling.
Mise owns download, verification and extraction.
**Tech Stack:** Lua 5.1 compatible code, mise, GitHub Actions.
**Spec:** ../specs/2026-10-29-raku-design.md

## Constraints and review focus

- Only advertise builds matching the runtime OS/architecture.
- Prefer the highest numeric build revision, independent of index row order.
- Reject untrusted asset origins and malformed publisher metadata.
- Match checksum filenames exactly; fail closed on missing SHA-256.
- Keep EnvKeys offline and expose zef as well as raku.
